# Website-Monster-Energy

## 🏁 Descripción del Proyecto
Website-Monster-Energy es un sitio web inspirado en la marca Monster Energy. El objetivo es mostrar información sobre los productos, competencias y experiencias relacionadas con la marca, utilizando una interfaz visual atractiva y moderna.

## 📁 Estructura del Proyecto

- `index.html`: Página principal del sitio.
- `pag-competencias.html`: Sección dedicada a competencias.
- `pag-experiencias.html`: Sección de experiencias y eventos.
- `pag-latas.html`: Información sobre las diferentes latas/productos.
- `css/`: Archivos de estilos CSS para cada sección y componentes generales.
- `img/`: Imágenes organizadas en subcarpetas (Competencia, Fondo, Latas, Logo).
- `js/`: Archivos JavaScript para funcionalidades y lógica del sitio.
- `readme/`: Capturas de pantalla del sitio web.
- `video/`: Videos utilizados en el sitio.

## 🚀 Instalación y Uso

1. Clona este repositorio:
   ```
   git clone <URL-del-repositorio>
   ```
2. Abre el archivo `index.html` en tu navegador preferido.
3. Asegúrate de mantener la estructura de carpetas (`css`, `js`, `img`, `video`) junto al archivo HTML.

## 🛠️ Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript
